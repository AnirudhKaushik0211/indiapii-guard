# IndiaPII Guard evaluation report

Version 1.0.0. Generated by `npm run eval`. Do not edit by hand.

All identifiers in samples, tests and evaluation data are randomly generated with valid structure and check digits. They are not linked to any person; any match with a real number would be coincidental. Card numbers are publicly documented test numbers. E-mail addresses use reserved example domains.

## How to read this

All numbers come from synthetic, self-constructed data. Labels come from the generator, so the evaluation measures agreement with the generator's conventions and cannot reveal formats the generator never produces. The templates were written by the same author as the detection rules. The held-out and adversarial templates were frozen before the first held-out run (see Development history). The numbers are not an estimate of accuracy on your data. Confidence intervals (Wilson, 95%) reflect sample size only. Card numbers come from a short public test list shared by all sets, so the held-out set tests card formats and contexts, not unseen card values. If any detector change after held-out run 1 cites an adversarial document (see Development history), the adversarial results are no longer unseen data.

This applies to this report: 3 detector change(s) after held-out run 1 cite adversarial documents.

Unsupported share 5.3%.
- Exact match (primary, used by the gate): same entity, start and end. Overlap match (secondary): same entity, at least one shared character, one-to-one greedy pairing by overlap length.
- Precision = tp / (tp + fp), recall = tp / (tp + fn), F1 = 2PR / (P + R); null when undefined. Micro sums over all nine entities; macro is the mean of the non-null per-entity values. Wilson 95% intervals (z = 1.959963985).
- Leak rate: letters and digits inside gold spans not covered by any prediction. Decoy hit: any prediction overlapping a decoy.
- Reproduce: `npm run eval` (all sets, writes the results); `npm run eval -- --write-data` also writes the datasets to `dist/eval-data/` for inspection; `node scripts/eval.cjs --check-repro` checks determinism.
